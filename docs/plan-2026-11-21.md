# Plan, 2026-11-21: stop grading ourselves, ship what works, then bring it to maps

Why: a read of `reports/Explainer video generation architectures.md` against the project log.
The architecture is right. What went wrong: quality was judged only by AI reviewers (which the
research shows disagree with people on teaching); five working days went to table lessons, none
of it in the app, while the target style is the system-design map; each review added rules.

## Step 1. Put the staged table planner into the app (in progress)
- A recipe `table_explainer` (board `trace`, `planner: staged_table`) that Jev and the keywords
  can choose: counting the ways, tilings, strings without a pattern, stairs, coins.
- `planner.lesson_plan.generate` tries `lesson_recurrence.generate` for it; if that fails, it
  falls back to the one-call trace lesson, so a client always gets a video. The fallback is
  logged as a retry with its reason.
- Tests with a scripted client: the staged route is used, and a failure falls back.
- Done when one live run through the web engine plans and renders a table topic.

## Step 2. A human verdict, not an AI score
- Render three videos from the app as a client would get them: a map lesson (system design),
  a staged table lesson, and an old one-call trace lesson.
- The owner (or a teacher) watches them and scores each on: would you publish it; did it teach
  the idea; what was the worst moment. That sheet is the measure from now on.

## Step 3. The staged design for map lessons (the target style)
- Model writes the teaching in plain text; code builds the map and every step; model writes
  one sentence per step with the facts in hand. Same split that lifted table lessons.
- Only after step 2's verdict, so it is aimed at what a person found wrong.

## Step 4. No new table-lesson rules until step 2 has a human score
- Open table faults (units, stale labels, lookup check question, no picture of the problem)
  wait for the verdict, then are fixed in the order it ranks them.

## Also
- Keep a log of topics that could not be planned or fell back (`out/coverage.jsonl`), the
  coverage number the research says nobody measures.
- Before any commit: unit tests, and the video regression with Docker Desktop running.
